# ssrw
# Техническое задание на разработку веб-приложения «Библиотека кодовых сниппетов»
# 1. Общие требования

Приложение должно представлять собой удобную платформу для сохранения, систематизации и быстрого поиска фрагментов кода с интуитивно понятным интерфейсом, адаптивным дизайном (desktop/tablet/mobile) и обеспечивать стабильную работу на любых устройствах.

Стек технологий:

Frontend: React, React Router, Context API.

Стили: CSS Modules.

Бэкенд: Node.js/Express.

База данных: PostgreSQL.

Технические требования к окружению:
Поддержка минимально необходимых версий браузеров (Chrome >= 60, Firefox >= 55, Edge >= 79, Safari >= 12). Кроссплатформенность.

# 2. Функциональные требования

# 2.1. Каталог и карточки сниппетов

Главная страница (Лента):

Пользователь видит список сохранённых сниппетов с пагинацией (по 20 записей на страницу).

Каждая карточка содержит: название языка, заголовок, теги, краткое описание (до 100 символов) или пометку «Без описания», дату создания.

Клик по карточке открывает страницу детального просмотра.

Страница сниппета:

Блок кода с нумерацией строк и подсветкой синтаксиса.

Отображение всех метаданных: название, язык, теги, полное описание, дата создания и последнего изменения.

Кнопка «Скопировать код» (копирует содержимое в буфер обмена, показывает подтверждение на 2 секунды).

Кнопки «Редактировать» и «Удалить» (доступны только владельцу записи).

# 2.2. Создание и редактирование

Форма добавления/редактирования:

Обязательные поля: название, язык (выпадающий список), код (textarea).

Необязательные поля: описание, теги (ввод через запятую).

Валидация: название и код не пустые, название уникально для текущего пользователя, длина кода ≤ 50 000 символов.

При сохранении данные отправляются на сервер. При успехе форма закрывается, список обновляется. Ошибки валидации отображаются под соответствующими полями.

# 2.3. Поиск и фильтрация

Поисковая строка:

Поиск по названию, описанию и тегам (регистронезависимый, частичное совпадение).

Фильтры и сортировка:

Выпадающий список для фильтрации по языку программирования.

Сортировка: «Сначала новые», «Сначала старые», «По алфавиту».

Результаты поиска и отфильтрованные записи отображаются в том же формате карточек, что и основная лента.

# 2.4. Пользователи и данные

Авторизация:

Регистрация и вход по email/паролю. После входа сессия сохраняется между перезагрузками страницы.

Разделение данных:

Каждый пользователь видит и может изменять только свои сниппеты. Попытка доступа к чужим записям возвращает ошибку авторизации.

Сохранение состояния:

При перезагрузке страницы восстанавливаются данные авторизации, текущий выбранный фильтр и страница списка.

# 3. Дополнительные функциональные требования (необязательно, но желательно)

Экспорт и импорт:

Кнопка «Экспорт в JSON» скачивает все сниппеты пользователя в виде файла.

Кнопка «Импорт из JSON» загружает файл и добавляет записи в базу. При совпадении названий новые записи пропускаются.

Тёмная тема:

Переключатель в шапке приложения. Выбор сохраняется в localStorage и применяется ко всем страницам.

Горячие клавиши:

Ctrl+K / Cmd+K — фокус на поле поиска, N — переход к созданию нового сниппета, Esc — закрытие модальных окон.
